### Speech runtime implementation findings — 17 October
The pinned Redux checkpoint is `moondream/parakeet-redux` at HF commit `2bf128600aac4b16946f7ed8372e56117fe5e23b`, with a 177,774,490-byte `model.safetensors` whose SHA-256 is `78ec25733ee0d0c1586d1346fc86db9d0c2e436e3a8ab1d32a82d1bb8f848d21`. Its model card lists 24 languages. Kestrel 0.9.1 otherwise resolves this repository's mutable `main`; runtime integration must instead use an app-data snapshot downloaded from this pinned commit and force local-only loading.

Photon's current Kestrel reporter sends usage telemetry to `api.moondream.ai` even without an API key. The isolated worker must disable its telemetry reporter before model initialization and force local-only inference; verify the worker has no unexpected outbound HTTP after runtime/model installation. Do not embed user speech in telemetry or logs. The optional runtime is substantially larger than the product installer: the pinned Torch CPU wheel alone is about 124 MB on Windows x64, 196 MB on Linux x64, and 127 MB on Apple Silicon, before Python, Kestrel dependencies, and the 178 MB checkpoint. Intel macOS has no supported Photon runtime in the reviewed package set and must use Vosk. Photon runtime bootstrap, model verification, telemetry isolation, and synthetic-WAV inference remain explicit completion gates; do not label them done until verified.
